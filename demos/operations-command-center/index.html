Demo Safety & Isolation

Separate demo dataAll records are generated inside this page or local browser storage.
No outbound emailButtons simulate reports and exports but do not send email.
No production credentialsNo Supabase keys, OAuth clients, Classroom tokens, or API endpoints are embedded.
No real personal informationEvery user, email, payroll amount, and training record is fictional.

Build Notes

For a real implementation, Arsenal Media would use a separate hosting project, separate database, separate environment variables, rate limiting, anti-bot protection, role-based access, and approved outbound email routes.
