Upload the contents of this package to the root of the GitHub repo.

Included:
- sitemap.xml
- robots.txt

Purpose:
- Replaces the old sitemap that Google Search Console showed as discovering only 1 page.
- Uses canonical HTTPS non-www URLs.
- Adds the current main service, portfolio, blog, app, about, and contact URLs.

After deployment:
1. Open https://arsenalmediaco.com/sitemap.xml and confirm many URLs appear.
2. Open https://arsenalmediaco.com/robots.txt and confirm it points to the sitemap.
3. In Google Search Console, remove the old sitemap if needed and resubmit sitemap.xml.
4. Use URL Inspection on https://arsenalmediaco.com/ and request indexing.
